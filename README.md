# Disabling_HDCP_on_NVIDIA_GPU
HDCP stands for High-Bandwidth Digital Content Protection (HDCP) is a technology designed to protect high- definition content. HDCP always runs on the background causing little amount of Latency and Performance drop in the system. So you might want to Disable HDCP on Nvidia GPU

how to disable HDCP!!!!
1. Download the Files and direct run it Or Copy the contents of the File
2. then paste this file contents on newly created text file
3. rename the file name with .reg extension
4. run the newly created reg file and press ok
5. then restart your PC

Same Steps for Re-enabling HDCP
